# 送料の決定ロジックについて

> 対象システム：POD Admin（受注管理システム）
> 作成日：2026-06-10

## 結論

**現在のシステムには「送料」を計算したり保存したりする仕組みはありません。**

注文金額に送料は含まれておらず、送料を表す項目もデータベース上に存在しません。

---

## よくある誤解（これらは「送料」ではありません）

「金額」や「配送」に関係する機能はありますが、いずれも送料とは別物です。

| 機能 | 何をするものか | 送料との関係 |
|------|----------------|--------------|
| 注文の合計金額 | 「商品単価 × 数量」を合計するだけ | 送料は **含まれていない** |
| 商品の価格計算 | 商品の種類・サイズごとに単価を決める | 商品代金であり送料ではない |
| 発送予定日の計算 | いつ発送できるかの「日付」を出す | 金額ではなく日付 |
| 配送業者の記録 | ヤマト等の業者名・追跡番号を保存 | 業者名のみで **料金は持たない** |

### 商品の単価（参考）

| 商品 | 単価 |
|------|------|
| Tシャツ | 870円（固定） |
| トートバッグ | 780円（固定） |
| アクリルキーホルダー | 285〜475円（サイズ別） |
| アクリルスタンド | 310〜735円（サイズ別） |
| ステッカー | 50〜79円（サイズ別） |

※ これらは「商品の値段」であり、配送にかかる送料ではありません。

---

## もし送料の仕組みを追加する場合

新しく作る必要があります。その際は、以下を決める必要があります。

- **送料の決め方**：全国一律 / 地域別 / 重量別 / 業者別 / 一定額以上で送料無料 など
- **金額の扱い**：商品代金と分けて表示するか、合計に含めるか
- **保存場所**：注文ごと、または出荷ごとに送料を記録する項目を追加

実装をご希望の場合は、上記の方針を決めていただければ対応可能です。
