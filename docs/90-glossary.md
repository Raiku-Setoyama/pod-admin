## アクター・認証

| 用語 | コード上の名前 | 定義 | 備考 |
|---|---|---|---|
| 管理者 / オペレーター | `UserRole.ADMIN` / `OPERATOR` | 管理画面を使う TOSYO 社内アカウント。現状ほぼ全管理機能は ADMIN 限定 | `users` テーブル |
| 製造委託先 / メーカー | `Manufacturer` | 製造を委託する外部業者。専用ポータルを持つ | `manufacturers` テーブル |
| 受注元 / 外部販売サイト | `OrderSource` | 受注を送ってくる外部の販売サイト | コード・APIキー・配送元情報を持つ |
| アクセストークン | access_token | API 呼び出し用の短命 JWT（既定30分） | |
| リフレッシュトークン | refresh_token | アクセストークン再発行用 JWT（既定7日）。現状は管理者のみ実運用 | |
| メーカートークン | manufacturer_token | メーカーポータル用の JWT。`manufacturer_id` で本人を解決 | |
| API キー | `X-API-Key` | 外部販売サイト連携の認証鍵。受注元単位 | 現状は平文保存 |
| 内部シークレット | `X-Internal-Secret` | cron 等の内部トリガ用の共有秘密 | 定数時間比較 |

## 受注

| 用語 | コード上の名前 | 定義 | 備考 |
|---|---|---|---|
| 受注 / 注文 | `Order` | 外部サイトからの 1 注文。注文番号・顧客情報・合計金額・配送予定日を持つ | |
| 受注明細 | `OrderItem` | 注文内の商品 1 行 | |
| 注文番号 | `order_number` | 外部サイト発番の 7 桁数字。システム内で一意 | |
| 製品番号 / UID | `uid` | 明細単位の 7 桁数字（外部サイトのオリジナル商品 ID） | 帳票・シールに使う |
| 注文ステータス | `OrderStatus` | 発注準備中 → 発注済み → 製造中 → 納入済み / 発送完了 / キャンセル済み | 明細から導出 |
| 明細ステータス | `OrderItemStatus` | 明細単位のステータス。メーカー画面が参照 | 注文と二層 |
| 実効受注日 / 起算日 | `effective_order_date` | 〆切考慮後のスケジュール計算の起算日 | 実受注時刻は別途保持 |
| 注文〆切時間 | `order_deadline_time` | これ以降着信の注文は起算日を翌営業日にする JST 時刻。空で無効 | |

## 商品・メーカー

| 用語 | コード上の名前 | 定義 | 備考 |
|---|---|---|---|
| 商品種別 | `product_type` / `ProductType` | Tシャツ/トートバッグ/アクリルキーホルダー/アクリルスタンド/ステッカーの5固定 | コード上の Enum |
| サイズ / 位置 / カラー | `size` / `position` / `color` | 商品の寸法・印刷位置・色。任意の文字列（マスタ非管理） | |
| 原価 | `cost` | 商品 1 点あたりの製造原価（円） | |
| リードタイム | `lead_time_days` | 発注から納品までの営業日数 | 商品・メーカー双方に存在 |
| 対応商品 | `supported_products` | メーカーが製造できる商品種別の配列 | |
| 商品別単価 | `unit_prices` | メーカーの商品種別ごとの単価 | 請求書で使用 |
| 共有方式 | `sharing_method` | メーカーへの資料共有手段（drive / portal）。既定は portal | 現状は portal に一本化 |
| 発注上限 | `order_limit` / `daily_order_limit` | 発注数の上限メタデータ | 現状は未強制 |

|---|---|---|---|

| 発注資料 | order-documents | メーカーへ渡す ZIP。タイプ別 Excel＋製造データ＋サムネイル | `TAPI_{名}_発注資料.zip` |

| スタンドファイル | _stand.ai | アクリルスタンド専用のサイズ別台座テンプレート（製造データ②） | |

## 配送・請求・通知

| 用語 | コード上の名前 | 定義 | 備考 |
|---|---|---|---|
| 配送 | `Shipment` | 1 件以上の注文を束ねた発送単位 | |
| 配送ステータス | `ShipmentStatus` | 配送準備待ち(pending) / 準備完了(ready) / 発送完了(shipped) | 双方向遷移可 |
| 商品準備中（注文） | pending_order / `PREPARING` | まだ配送レコードが作られていない未発送の注文 | 配送一覧に統合表示 |
| 納品予定日 | `expected_delivery_date` | 明細単位。起算日＋商品リードタイム（営業日） | メーカー納品の予定 |
| 配送予定日 | `estimated_shipping_date` | 注文単位。最遅の納品予定日＋発送準備日数 | 顧客配送の予定 |
| 発送準備日数 | `shipping_preparation_days` | 納品完了後〜発送までの営業日数。既定5 | 設定で変更可 |
| 営業日 | `is_business_day` | 土日・日本の祝日・自社休日を除いた日 | jpholiday を使用 |
| 独自休日 / 会社休日 | `CompanyHoliday` | 夏季休暇など土日祝以外の自社休業日 | |
| 伝票番号 / 追跡番号 | `tracking_number` | 配送業者の追跡番号 | |
| 運送会社 | `carrier` | 配送業者名 | |
| 請求書番号 | invoice number | `INV-YYYYMMDD-{ID先頭5桁}{通番}` 形式 | |
| 支払期日 | payment_due_date | 請求書発行日の翌月末 | |
| 日次発注ダイジェスト | daily digest | メーカー宛の 1 日 1 回・新規発注分のサマリーメール | |
| ウォーターマーク | `last_notified_at` | メーカー別「新規分」判定の基準時刻。送信成功時のみ更新 | |
| 送信者種別 | `MessageSender` | チャットの送信元（admin / manufacturer） | 表示の左右振り分け |

## 使い分けに注意する用語

| 用語A | 用語B | 違い |
|---|---|---|
| 受注（order） | 発注（purchase-order） | 外部サイト→自社が「受注」、自社→メーカーが「発注」 |
| 注文ステータス | 明細ステータス | 前者は注文全体、後者は明細単位。二層で双方向に同期 |
| 発注準備中 | 発注済み | 製造データ未 ready で発注不可 / ready で発注可 |
| 納品予定日 | 配送予定日 | 前者はメーカー→自社の納品（明細）、後者は自社→顧客の配送（注文） |
| 商品準備中 | 配送準備中 | 前者は配送レコード未作成の注文、後者は配送(pending)ステータス |
| v1 | v2 | 完成デザイン URL 方式 / 元データを受けて製造データを生成する方式 |
