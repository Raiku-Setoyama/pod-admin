## 内容
外部販売サイト経由で受注が入った際、社内の担当者へ受注通知メールを自動送信する。通知の有効／無効と送信先の宛先は設定で変更できる。

## 背景・理由
背景は未確認（既存実装からの逆算のため）。外部販売サイトから入る受注に社内担当者がすぐ気づけるよう、受注時に自動でメール通知を送りたい。運用状況に応じて通知の要否や宛先を切り替えられる必要があるため、設定で制御できる受注通知メールが必要となる。

## 詳細
外部受注取り込みAPI（v1／v2）で受注が作成されたタイミングで、社内担当者へ受注通知メールを送信する。通知の有効／無効と宛先リストは全社共通設定（app_settings）で管理し、有効かつ宛先がある場合のみ送信する。メール送信はバックグラウンドタスクで非同期に行い、受注登録処理をブロックしない。メール送信で例外が発生しても握りつぶし、受注登録自体は成功として扱う。

主なエンドポイント:
- `POST /api/v1/orders` — 外部受注取り込みv1（受注作成後に受注通知メールを非同期送信）
- `POST /api/v2/orders` — 外部受注取り込みv2（受注作成後に受注通知メールを非同期送信）

## 受入基準
- [x] 外部受注取り込みAPI（v1／v2）で受注が作成されると社内担当者へ受注通知メールが送信される
- [x] 通知の有効／無効を設定（app_settings）で切り替えられ、無効時は送信されない
- [x] 送信先の宛先を設定（app_settings）で指定でき、宛先が無い場合は送信されない
- [x] メール送信はバックグラウンドタスクで非同期に行われ、受注登録処理をブロックしない
- [x] メール送信で例外が発生しても受注登録は成功として扱われる
