## 内容

配送一覧の並び順を操作できるようにしたい、という要望をいただいている。

**どの列で、どちら向きに並べたいかは未確認である。** 現状は作成日の降順に固定で、
画面から並び順を変える手段がない。

## 背景・理由

背景は未確認（「ソート順も要望」とのみ伺っている）。

現状:

- API（`GET /shipments`）は `sort_by`（`created_at` / `shipped_at` / `delivered_at`）と
  `sort_order` に対応しているが、配送一覧の画面からは配線されていない
  （フロントは既定値の `created_at` / `desc` を送るだけ。REQ-0026 のスコープ外に記載済み）
- 一覧に出ている「配送予定日」「注文番号」「宛先」「ステータス」では、API 側も並び替えできない
- **並び順を指定しても一覧全体には効かない。** 配送一覧は実配送と準備中注文を
  別々のクエリで取得して連結しており、`sort_by` は実配送側にしか効かない
  （準備中注文は常に受注日の降順）。1 ページの中で 2 つの並びが混ざる

そのため、この要望は「画面にソート UI を足す」だけでは満たせない可能性が高い。
統合方式の見直しが要るかどうかは [NEEDS-DECISION: ADR-0025] で判断を待っている。

## 判断が出ないと止まるもの

- どの列で並び替えたいか（作成日 / 配送予定日 / ステータス / 注文番号 / 宛先 / 発送日 …）
- 既定の並び順をどうするか（現状は作成日の降順）
- 実配送と準備中注文を通した並びが必要か、それとも実配送の中だけ並べば足りるか
  → ADR-0025 の判断材料になる
