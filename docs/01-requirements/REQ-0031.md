## 内容
管理者と製造委託先は、メーカーごとのスレッドでテキストメッセージやファイル添付をやり取りでき、送られてきた添付ファイルをダウンロードできる。

## 背景・理由
背景は未確認（既存実装からの逆算のため）。発注や製造にまつわる連絡を、メーカー単位でテキストと資料の添付を交えてやり取りする手段が必要なため、管理者と製造委託先の双方が使えるチャット機能が必要となる。

## 判断が出ないと止まるもの
なし

## 詳細
メーカーごとに1本のスレッドを持ち、管理者側と製造委託先ポータル側の双方から同じスレッドへ投稿する。メッセージは送信者種別（管理者／製造委託先）で区別する。本文または添付のいずれかは必須で、どちらも無い場合は 400 を返す。添付は最大10MBかつ許可されたMIMEタイプのみ受け付け、日本語ファイル名も保持する。画面はポーリングで更新する。

主なエンドポイント:
- `GET /chat/manufacturers/{id}` — 管理者がメーカーのスレッドのメッセージ一覧を取得する
- `POST /chat/manufacturers/{id}` — 管理者がメッセージ（本文／添付）を投稿する
- `GET /chat/attachments/{id}` — 添付ファイルをダウンロードする
- `GET /manufacturer-portal/chat` — 製造委託先がポータルから自社スレッドのメッセージ一覧を取得する
- `POST /manufacturer-portal/chat` — 製造委託先がポータルからメッセージ（本文／添付）を投稿する

## 受入基準
- [x] 管理者と製造委託先が同じメーカー単位のスレッドでメッセージをやり取りでき、送信者種別（管理者／製造委託先）で区別される
- [x] 本文または添付のいずれかが無い場合は 400 を返す
- [x] 添付は最大10MB・許可されたMIMEタイプのみ受け付ける
- [x] 添付ファイルの日本語ファイル名が保持される
- [x] `GET /chat/attachments/{id}` で添付ファイルをダウンロードできる
- [x] チャット画面はポーリングで更新される
