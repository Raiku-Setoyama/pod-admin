## 内容
受注が入ると、システムが注文の〆切時刻と営業日（土日祝・自社の独自休日）をふまえて、納品予定日と配送予定日を自動で計算する。管理者や外部システムが手作業で日付を数える必要はない。

## 背景・理由
背景は未確認（既存実装からの逆算のため）。製造リードタイムと発送準備を営業日ベースで正しく見込み、顧客に一貫した納期・配送予定を示すため、日付計算を自動化する必要がある。

## 詳細
受注時刻に対して、注文〆切時刻（order_deadline_time、HH:MM JST）を基準に起算日（実効受注日）を決める。〆切を過ぎた受注は起算日のみ翌営業日へ繰り下げられる（実際の受注時刻はそのまま保持される）。営業日は jpholiday による土日祝に加え、自社の独自休日（会社休日）を除いて判定する。

- 納品予定日（expected_delivery_date、明細ごと）＝ 起算日にリードタイムぶんの営業日を加算した日
- 配送予定日（estimated_shipping_date、注文）＝ 各明細の納品予定日の最大値に、発送準備日数を加えた日

主なエンドポイント:
- 受注取り込み（`POST /api/v1/orders`, `POST /api/v2/orders`）で受注が作成される際に、納品予定日・配送予定日が自動計算される

## 受入基準
- [x] 注文〆切時刻（order_deadline_time）を過ぎた受注は、起算日のみが翌営業日へ繰り下がる
- [x] 起算日が繰り下がっても、実際の受注時刻（ordered_at）は保持される
- [x] 営業日の判定で、土日祝（jpholiday）と自社の独自休日（会社休日）が除外される
- [x] 納品予定日は、起算日にリードタイムぶんの営業日を加算して算出される
- [x] 配送予定日は、各明細の納品予定日の最大値に発送準備日数を加えて算出される
