## 内容
製造委託先は、メーカーポータルで自社に割り当てられた発注明細の一覧を確認でき、注文番号・製造番号・商品名やステータスで検索・絞り込みして閲覧できる。

## 背景・理由
背景は未確認（既存実装からの逆算のため）。製造委託先が自社宛の発注内容を把握し、製造を進めるために、自社の発注明細を一覧で確認・検索できる画面が必要となる。

## 詳細
自社（商品のメーカー紐付け）に該当する発注明細を一覧で取得する。ステータス未指定時は発送済みを除く全明細を対象とし、注文番号・製造番号（uid）・商品名による検索とステータスによる絞り込みに対応する。あわせて件数・数量合計・金額合計を集計して返す。

主なエンドポイント:
- `GET /manufacturer-portal/order-items` — 自社の発注明細一覧（検索・ステータス絞り込み、件数・数量合計・金額合計の集計付き）

## 受入基準
- [x] `GET /manufacturer-portal/order-items` で自社（商品のメーカー紐付け）に該当する発注明細一覧が取得できる
- [x] ステータスを指定しない場合は発送済みを除く全明細が対象になる
- [x] 注文番号・製造番号（uid）・商品名で検索できる
- [x] ステータスで絞り込みできる
- [x] 一覧に件数・数量合計・金額合計の集計が含まれる
