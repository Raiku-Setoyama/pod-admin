## 内容
管理者は、ダッシュボードで本日の受注件数・発送件数と、発注・発送のステータス別内訳を確認できる。

## 背景・理由
背景は未確認（既存実装からの逆算のため）。日々の業務量と処理状況をひと目で把握するため、本日の受注・発送件数や、発注・発送の進み具合をステータス別に集計して表示するダッシュボードが必要となる。

## 判断が出ないと止まるもの
なし

## 詳細
ダッシュボード用の集計サマリーを1つのエンドポイントで返す。本日の受注件数（orders_today）・本日の発送件数（shipments_today）、注文ステータス別の件数、発注中（ordered）件数・製造中（manufacturing）件数を返す。発送待ち件数は pending と ready の合算としてフロントエンドで算出する。集計はキャッシュを持たずサービス層で都度SQL集計し、画面はポーリングで更新する。

主なエンドポイント:
- `GET /dashboard/summary` — ダッシュボードの集計サマリー（本日の受注・発送件数、ステータス別件数、発注中・製造中件数）を取得する

## 受入基準
- [x] `GET /dashboard/summary` で本日の受注件数・本日の発送件数が取得できる
- [x] 注文ステータス別の件数が取得できる
- [x] 発注中（ordered）件数・製造中（manufacturing）件数が取得できる
- [x] 発送待ち件数が pending と ready の合算としてフロントエンドで算出・表示される
- [x] ダッシュボードはポーリングで更新される

## スコープ外
売上金額の集計は未実装で、集計は件数のみを扱う。また発注・発送のステータス別内訳はAPIで返るが、トップ画面では未可視化（StatusOverview が未使用）である。
