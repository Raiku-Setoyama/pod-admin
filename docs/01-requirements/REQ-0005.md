## 内容
管理者は、受注の一覧を見ながら、注文ステータスや商品種別、受注日・配送予定日の範囲、キーワード（注文番号・顧客名）で目的の受注を絞り込める。件数が多い場合はページを送って続きを確認できる。

## 背景・理由
背景は未確認（既存実装からの逆算のため）。日々多数の受注を扱う管理者が、対応すべき受注を素早く見つけられるようにするため、一覧の検索・絞り込みとページ送りが必要となる。

## 判断が出ないと止まるもの
なし

## 詳細
管理者は受注一覧画面で、注文ステータス・商品種別・受注日の範囲・配送予定日の範囲・キーワードを指定して受注を絞り込む。キーワードは注文番号と顧客名を対象に検索される。結果はページ単位で返され、ページを送って続きを閲覧できる。バックエンドはステータス・商品種別・受注日範囲（ordered_from / ordered_to）・配送予定日範囲（shipping_from / shipping_to）・キーワードの各条件と、ページングに対応している。

主なエンドポイント:
- `GET /orders` — 受注一覧を検索条件（status / product_type / ordered_from / ordered_to / shipping_from / shipping_to / search）とページ指定で取得する

## 受入基準
- [x] `GET /orders` に注文ステータスを指定すると、そのステータスの受注のみが返る
- [x] `GET /orders` に商品種別を指定すると、その商品種別の受注のみに絞り込まれる
- [x] `GET /orders` に受注日の範囲（ordered_from / ordered_to）を指定すると、その期間の受注のみが返る
- [x] `GET /orders` に配送予定日の範囲（shipping_from / shipping_to）を指定すると、その期間の受注のみが返る
- [x] `GET /orders` にキーワードを指定すると、注文番号または顧客名に一致する受注が返る
- [x] `GET /orders` はページ指定に対応し、件数が多い場合にページを送って続きを取得できる
- [x] 受注一覧画面から、キーワード・注文ステータス・ページ送りで受注を絞り込める

## スコープ外
- 商品種別・受注日/配送予定日の範囲フィルタはバックエンド（`GET /orders`）で実装済みだが、受注一覧画面のUIからは未配線（画面上の入力欄と接続されていない）。
