## 内容
管理者は、発注中の受注明細をメーカー（製造委託先）ごとに集計した発注サマリーを一覧で確認でき、特定メーカーの発注明細や、全メーカー横断の発注明細一覧も参照できる。

## 背景・理由
背景は未確認（既存実装からの逆算のため）。どのメーカーに何をどれだけ発注しているかをメーカー単位で把握し、発注業務を進めるために、発注中の明細をメーカー別に集計して確認できる画面が必要となる。

## 判断が出ないと止まるもの
なし

## 詳細
発注中（ORDERED）の受注明細を、稼働中のメーカーごとに集計する。各メーカーについて対象明細の件数・数量合計・金額合計（単価×数量の合計）を算出し、最新の注文日の降順で並べる。特定メーカーの発注明細、および全メーカー横断の発注明細一覧を取得でき、検索・フィルタに対応する。

主なエンドポイント:
- `GET /manufacturers/order-summary` — 発注中の明細をメーカー別に集計した発注サマリー一覧（件数・数量合計・金額合計、最新注文日の降順）
- `GET /manufacturers/{id}/order-items` — 特定メーカーの発注明細一覧
- `GET /manufacturers/all-order-items` — 全メーカー横断の発注明細一覧

## 受入基準
- [x] `GET /manufacturers/order-summary` で、発注中（ORDERED）の明細を稼働中メーカー別に集計した発注サマリーが取得できる
- [x] 発注サマリーの各メーカーに、対象明細の件数・数量合計・金額合計（単価×数量の合計）が含まれる
- [x] 発注サマリーは最新の注文日の降順で並ぶ
- [x] `GET /manufacturers/{id}/order-items` で特定メーカーの発注明細一覧が取得できる
- [x] `GET /manufacturers/all-order-items` で全メーカー横断の発注明細一覧が取得でき、検索・フィルタが利用できる

## スコープ外
メーカー別の集計は受注明細（OrderItem）のステータスを基準とし、横断の受注状況は受注（Order）のステータスで扱うため、両者は集計粒度が異なる。
