## 内容
管理者は、選んだ受注について、配送用のCSVファイル・デザイン画像をまとめたZIP・サムネイル画像をまとめたZIPを出力できる。製造や出荷の実務で使う資材を、その場でダウンロードできる。

## 背景・理由
背景は未確認（既存実装からの逆算のため）。配送手配や製造への受け渡しを効率化するため、受注データを実務で使える形式（CSV・画像一括ZIP）で出力できる必要がある。

## 詳細
管理者は選択した受注を対象に、配送CSV・デザイン画像ZIP・サムネイルZIPを出力する。配送CSVは18列で、UTF-8 BOM付き（Excel互換）で生成される。デザイン画像ZIPは各明細のデザイン画像（design_image_url）を最大10並列で取得してまとめる。

主なエンドポイント:
- `POST /orders/export-csv` — 選択受注の配送CSV（18列・BOM付き）を出力する
- `POST /orders/download-images` — 選択受注のデザイン画像（design_image_url）をZIPで出力する（最大10並列で取得）
- `POST /orders/download-thumbnails` — 選択受注のサムネイル画像をZIPで出力する

## 受入基準
- [x] `POST /orders/export-csv` で選択受注の配送CSV（18列・UTF-8 BOM付き）を出力できる
- [x] `POST /orders/download-images` で選択受注のデザイン画像（design_image_url）をZIPで出力でき、取得は最大10並列で行われる
- [x] `POST /orders/download-thumbnails` で選択受注のサムネイル画像をZIPで出力できる

## スコープ外
- デザイン画像ZIP出力は受注一覧画面のUIから配線済みだが、配送CSV出力・サムネイルZIP出力はバックエンド実装済みでUIからは未配線。
