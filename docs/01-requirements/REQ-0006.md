## 内容
管理者は、1件の受注を選ぶと、その受注の顧客情報・注文された商品の明細・配送情報・製造データの状態をまとめて確認できる。製造データを生成している最中は、状態が自動で更新されていく様子を見られる。

## 背景・理由
背景は未確認（既存実装からの逆算のため）。受注1件ごとの内容を正確に把握して製造・出荷を進めるため、関連情報を一画面で閲覧できる必要がある。

## 判断が出ないと止まるもの
なし

## 詳細
管理者は受注詳細画面で、対象受注の顧客情報・商品明細（各明細の製品番号UIDを含む）・配送情報・製造データの状態を閲覧する。製造データを生成中の受注については、画面が一定間隔（5秒）でポーリングして最新状態を反映する。

主なエンドポイント:
- `GET /orders/{id}` — 1件の受注の顧客情報・商品明細・配送情報・製造データ状態を取得する

## 受入基準
- [x] `GET /orders/{id}` で対象受注の顧客情報が取得できる
- [x] `GET /orders/{id}` で対象受注の商品明細が取得できる
- [x] `GET /orders/{id}` で対象受注の配送情報が取得できる
- [x] `GET /orders/{id}` で対象受注の製造データの状態が取得できる
- [x] 製造データ生成中の受注は、詳細画面が5秒間隔でポーリングして状態を更新する
