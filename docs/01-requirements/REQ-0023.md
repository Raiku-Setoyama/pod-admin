## 内容
製造委託先は、メーカーポータルにログインし、自社のプロフィール情報（電話番号・住所・代表者・銀行口座・請求書備考）を自分で確認・編集できる。

## 背景・理由
背景は未確認（既存実装からの逆算のため）。製造委託先の連絡先や振込先などの情報は請求書発行や連絡に用いられるため、変更が生じた際に製造委託先自身がポータルから更新できるようにする必要がある。

## 判断が出ないと止まるもの
なし

## 詳細
製造委託先はメーカーポータルにログインし、自社のプロフィールを取得・更新する。編集できるのは住所・代表者・銀行口座・請求書備考などの自社情報に限られ、会社名・メールアドレスは管理者管轄のため編集できない。

主なエンドポイント:
- `POST /manufacturer-portal/login` — 製造委託先がポータルにログインする
- `GET /manufacturer-portal/profile` — 自社のプロフィール情報を取得する
- `PATCH /manufacturer-portal/profile` — 自社のプロフィール情報（電話・住所・代表者・銀行口座・請求書備考）を更新する

## 受入基準
- [x] `POST /manufacturer-portal/login` で製造委託先がポータルにログインできる
- [x] `GET /manufacturer-portal/profile` で自社のプロフィール情報を取得できる
- [x] `PATCH /manufacturer-portal/profile` で電話・住所・代表者・銀行口座・請求書備考を更新できる
- [x] 会社名・メールアドレスは編集対象に含まれず、ポータルからは変更できない

## スコープ外
会社名・メールアドレスは管理者管轄のため、ポータルからは編集できない（管理画面のメーカー管理でのみ変更する）。
