## 内容
管理者は、配送一覧で実際の配送レコードと「商品準備中の注文」を統合して表示でき、種別・ステータス・伝票番号・配送ID・顧客名などで検索・絞り込みできる。

## 背景・理由
背景は未確認（既存実装からの逆算のため）。まだ配送レコードが生成されていない準備中の注文と、実際の配送レコードをひとつの一覧でまとめて把握し、発送業務を進めるために、両者を統合した配送一覧が必要となる。

## 判断が出ないと止まるもの
なし

## 詳細
配送一覧は、実配送（shipment）と商品準備中の注文（pending_order）を統合して返す。種別（shipment／pending_order）、ステータス（pending／ready／shipped／preparing）、伝票番号・配送ID・顧客名による検索・絞り込みに対応する。

主なエンドポイント:
- `GET /shipments` — 実配送と商品準備中注文を統合した配送一覧（種別・ステータス・検索での絞り込み）

## 受入基準
- [x] `GET /shipments` で実配送（shipment）と商品準備中注文（pending_order）が統合された一覧が取得できる
- [x] 種別（shipment／pending_order）で絞り込みできる
- [x] ステータス（pending／ready／shipped／preparing）で絞り込みできる
- [x] 伝票番号・配送ID・顧客名で検索できる

## スコープ外
伝票番号・運送会社・発送日/配達日の範囲、および並び替えはバックエンド（API）側で実装済みだが、配送一覧UIからは未配線のため画面上では利用できない。
