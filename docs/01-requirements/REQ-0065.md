## 内容

「すべての発注」画面（`/purchase-orders/all`）で、「製造中」「納品済」「キャンセル済」の
明細も表示されるようにしたい。メーカー発注画面と同じように、**すべての発注が表示される**
状態にしてほしい。

その月に納品された商品分を月末にまとめて CSV でダウンロードし、請求書等に使いたい。

## 背景・理由

現状の「すべての発注」画面は、月末の締め作業に使えない。

1. **納品まで進んだ明細が一覧から消える。** 配送が発送完了になると注文全体が一覧から
   除外されるため、その月に納品した明細を月末に集計できない。
2. **表示・絞り込みが明細ではなく注文のステータスで行われる。** 複数メーカーにまたがる
   注文では、あるメーカーの明細が納品済でも、別メーカーの明細が製造中なら一覧上は
   「製造中」と表示され、「納品済」で絞り込んでも出てこない。

同じ画面の CSV ダウンロードと請求書発行は、この一覧に出ている明細だけを対象にするため、
一覧から漏れた明細は請求の対象にできない。

## 詳細

「すべての発注」画面（`GET /manufacturers/all-order-items`）を、メーカー発注画面
（`GET /manufacturers/{id}/order-items`）と同じ基準に揃える。

### 現状と変更後

| | 現状 | 変更後 |
|---|---|---|
| 既定で返す範囲 | 注文ステータスが発送完了のものを除外 | 除外しない（全件） |
| ステータスの絞り込み対象 | `Order.status`（注文単位） | `OrderItem.status`（明細単位） |
| 一覧・CSV に出るステータス | `Order.status` | `OrderItem.status` |

明細ステータスの語彙は 発注準備中 / 発注済み / 製造中 / 納入済み / キャンセル済み の 5 つで、
画面のステータス絞り込みの選択肢と一致する。発送完了は注文単位のステータスであり、
明細は納入済みのまま残るため、発送済みの明細は「納品済」として一覧に出る。

### 例外・エッジケース

- 複数メーカーにまたがる注文では、明細ごとに異なるステータスが表示される（意図した挙動）。
- 発送完了後も明細が残るため、一覧の件数は運用とともに増える。絞り込み（メーカー・
  ステータス・受注日・納品予定日・キーワード）で対象を狭める運用とする。

## 受入基準

- [x] 「すべての発注」画面で、注文が発送完了になった明細も一覧に表示される
- [x] 一覧・CSV のステータス列に、注文ではなく明細のステータス（発注準備中／発注済み／製造中／納入済み／キャンセル済み）が表示される
- [x] ステータス絞り込みで「製造中」「納品済」「キャンセル済」を選ぶと、その明細ステータスの明細だけが返る
- [x] 複数メーカーにまたがる注文で、納品済の明細がメーカーごとに独立して「納品済」で絞り込める
- [x] 上記を検証する回帰テストが追加されている

## スコープ外

- **実際の納品日は記録していない。** 「その月に納品された分」の抽出は、納品予定日または
  受注日の範囲指定で代用する。納品日そのものでの絞り込みは本要件では扱わない。
- 一覧のページング。この画面の CSV ダウンロードは表示中の全件を対象にするため、
  ページングを入れると月末の一括出力ができなくなる。
- 商品タイプ・発注日フィルタの UI 欠落（REQ-0045）。
