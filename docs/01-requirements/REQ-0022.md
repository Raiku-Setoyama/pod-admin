## 内容
管理者は、製造データを管理画面から再作成でき、元画像（レイヤー画像）を差し替えできる。ただしこれらは製造に着手する前に限る。

## 背景・理由
背景は未確認（既存実装からの逆算のため）。生成された製造データや元画像に修正が必要になった場合に備え、製造着手前であれば管理画面から作り直し・差し替えができる必要がある。一方で、製造中のものを書き換えると現場との齟齬が生じるため、着手後は不可とする。

## 判断が出ないと止まるもの
なし

## 詳細
製造データの再作成・元画像差し替え・リトライを管理画面から行う。再作成や差し替えの前に、対象が書き換え可能かを判定する（生成中は拒否、製造中で共有されている場合は 409 で拒否）。元画像の差し替えは、レイヤー種別（color／cutline／white／design）の置換に限り、PNG のマジックバイトを検証する。差し替え時は差し替え日時・実施者（replaced_at／replaced_by）を記録する。リトライは失敗（FAILED）状態のものだけを対象とする。製造データの一覧・詳細・プレビューも参照できる。

主なエンドポイント:
- `POST /manufacturing-data/{id}/regenerate` — 製造データを再作成する（着手前のみ、書き換え可否を判定）
- `POST /manufacturing-data/{id}/source-images` — 元画像（レイヤー画像）を差し替える（レイヤー種別置換のみ、PNGマジックバイト検証、差し替え日時・実施者を記録）
- `POST /manufacturing-data/{id}/retry` — 失敗（FAILED）状態の生成をリトライする
- `GET /manufacturing-data` — 製造データの一覧・詳細・プレビューを参照する

## 受入基準
- [x] `POST /manufacturing-data/{id}/regenerate` で製造データを再作成できる
- [x] 生成中の製造データは再作成・差し替えを拒否し、製造中で共有されている場合は 409 で拒否する
- [x] `POST /manufacturing-data/{id}/source-images` で元画像を差し替えられ、置換できるのはレイヤー種別（color／cutline／white／design）に限られる
- [x] 元画像の差し替えで PNG のマジックバイトが検証される
- [x] 元画像の差し替え時に差し替え日時・実施者（replaced_at／replaced_by）が記録される
- [x] `POST /manufacturing-data/{id}/retry` は失敗（FAILED）状態の製造データだけを対象とする
- [x] `GET /manufacturing-data` で製造データの一覧・詳細・プレビューが参照できる

## スコープ外
再作成・差し替えは製造着手前に限定し、製造中で共有済みの製造データは書き換えない。差し替えはレイヤー種別の置換のみで、任意ファイルの差し替えは扱わない。
