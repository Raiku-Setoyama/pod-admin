## 内容

全メーカー横断の受注明細一覧で、商品タイプ・発注日（From/To）による絞り込みが画面から操作できない。フィルタとしては存在するのに、値を変える手段が無い状態になっている。

## 背景・理由

REQ-0041 の実装中、eslint の未使用変数の指摘から見つかった。

`web/src/features/purchase-orders/components/all-manufacturer-order-filters.tsx` は、親から次の 3 つのハンドラを受け取っているが、**コンポーネント内で一度も使っていない**。

- `onProductTypeChange`
- `onOrderedFromChange`
- `onOrderedToChange`

一方で、対応する値（`productType` / `orderedFrom` / `orderedTo`）は受け取っており、「フィルタが有効かどうか」の判定（`hasActiveFilters`）には数えられている。つまり、

- 値が設定されていれば「フィルタ適用中」と表示されうるが、利用者がその値を変更・解除する UI が無い。
- API 側（`get_all_order_items`）は `product_type` / `ordered_from` / `ordered_to` を受け付けており、**バックエンドの機能は存在する**。

UI の作り忘れなのか、意図的に出していないのかは、要確認である。

## 判断が出ないと止まるもの

- この 3 つの絞り込みを画面に出すのか、機能ごと落とすのか（顧客の運用に依存する）。
- 出す場合、商品タイプの選択肢とレイアウト。
