## 内容
管理者は、取り扱う商品を種別・サイズ・印刷位置・カラー・原価・リードタイム（納期日数）・既定メーカー・有効状態などの属性とともにマスタ登録できる。登録済みの商品は、一覧で確認し、内容を編集し、不要になったものは削除できる。一覧は種別・メーカー・有効状態で絞り込め、件数が多い場合はページを送って確認できる。

## 背景・理由
背景は未確認（既存実装からの逆算のため）。受注や製造を扱う前提として、扱う商品の仕様・原価・納期・担当メーカーを一元的に管理する商品マスタが必要となるため。

## 詳細
管理者は商品管理画面から商品を登録・編集・削除し、一覧を閲覧する。一覧はページネーション（既定20件・最大100件）に対応し、商品種別・メーカー・有効状態でフィルタできる。一覧取得時には商品に紐づくメーカー名を結合して返す。削除は物理削除で行われる。なお一覧のキーワード検索パラメータは受理されるが実際の絞り込みには使われない（no-op、後述のスコープ外）。

主なエンドポイント:
- `GET /products` — 商品一覧を取得する（種別・メーカー・有効状態フィルタ、ページング、メーカー名結合）
- `GET /products/{id}` — 商品を1件取得する
- `POST /products` — 商品を新規登録する
- `PATCH /products/{id}` — 商品を編集する
- `DELETE /products/{id}` — 商品を削除する（物理削除）

## 受入基準
- [x] `POST /products` で、種別・サイズ・位置・カラー・原価・リードタイム・既定メーカー・有効状態を指定して商品を新規登録できる
- [x] `GET /products/{id}` で、登録済みの商品を1件取得できる
- [x] `PATCH /products/{id}` で、登録済みの商品の内容を編集できる
- [x] `DELETE /products/{id}` で、商品を削除できる（物理削除）
- [x] `GET /products` は商品種別・メーカー・有効状態で絞り込める
- [x] `GET /products` はページ指定に対応し、既定20件・最大100件でページを送れる
- [x] `GET /products` の一覧には各商品のメーカー名が結合されて返る

## スコープ外
- 一覧のキーワード検索パラメータ（search）は受理されるが実際の絞り込みには使われない（no-op）。かつて存在した商品名（name）フリーテキストが廃止されたことに伴う死蔵パラメータで、画面上にも検索ボックスは無い。
- 削除は物理削除であり、過去の受注が参照している商品を削除した場合の整合性は担保していない。
