## 内容

製造データ生成 VM（illustrator-vm）の Illustrator スクリプトが書く処理ログを、
VM に入らなくても Cloud Logging で読めるようにしたい。

## 背景・理由

BUG-0003 の調査で、アクリルスタンドのスクリプトは `scripts/debug_acrylic_stand.log`
（VM 内のファイル）にしかログを書かず、Cloud Logging に届くのは生成 API のログだけだと分かった。
タブの合成を飛ばしたことはこのファイルにしか残らず、本番では誰も気づけなかった。
原因の特定も、手元で同じ入力を流し直して初めてできた。

BUG-0003 の修正で「合成できなければジョブを失敗させる」ようになったので、同種の欠落は
失敗として表に出る。ただし、失敗の詳細や成功した生成の途中経過は、今も VM の中にしか無い。

なし（急がない）
