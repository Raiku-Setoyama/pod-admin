## 現象

アクリル系の製造データで、印刷画像の絵に囲まれた透明なすき間（かごの持ち手の輪の内側、
キャラクターの耳とピアノの譜面台のあいだなど）が、白版（White レイヤー）で埋まっている。
印刷では、透明なアクリルのはずのすき間に白インキが乗る。

製造委託先の指摘（BUG-0004 / BUG-0005）を調べる中で見つかった。印刷画像の背景を透過させると（BUG-0004）、
Illustrator 上で印刷画像の外に白版が見えるようになり、気づいた。製造委託先からこの点の指摘は出ていない。

## 再現手順

**指摘の 4 件の元データでの再現（確認済み、2026-10-26）:**

1. 販売サイトの本番 DB から、元データ（`submission_data` の design / shiroosae）を取得する
2. 白版の補正（`api/app/generator/white_plate.py` の `fill_white_plate`）を、印刷画像と白版画像に対して動かす
3. → 期待と異なり、印刷画像が透明なすき間を囲む白版の穴が、すべて埋まる。「本当の抜き」として残る穴が無い

| 製造データ | 補正が埋めた穴 | 本当の抜きとして残した穴 | 大きな穴の中身 |
|---|---|---|---|
| 1000169（キーホルダー 50mm、かごの中の猫） | 18 | 0 | かごの持ち手の輪の内側（44.1mm²）。縁より内側は 94% が完全に透明、濃い絵（不透明度 50% 以上）は 0% |
| 1000170（キーホルダー 70mm） | 0（外周の切れ込み 1） | 0 | — |
| 1000174（スタンド 100mm、ピアノを弾く女の子） | 5 | 0 | 耳とピアノの譜面台のあいだ（47.8mm²）など 2 か所。縁より内側は 94〜98% が完全に透明、濃い絵は 0% |
| 1000178（キーホルダー 70mm） | 0（外周の切れ込み 2） | 0 | — |

「縁」は、穴の縁から白版の内寄せの幅（0.2〜0.5mm）＋2px 以内。大きな穴の中の濃い絵は、100% がこの縁にある。

## 違反している受入基準

> REQ-0067 の受入基準「白版画像の、絵がある穴と半透明による外周の切れ込みが埋まり、完全に透明な穴は残ること」

REQ-0067 の内容も「完全に透明な穴（本当の抜き）は残す」としている。上の大きな穴は、中身が本当の抜きなのに埋まっている。
穴の縁には絵がかかるため文言の上では判定に幅があったが、2026-10-26 に依頼者が「意図しない不具合」と判断した。

## 影響範囲

- 2026-10-12 以降に生成されたアクリル系（白版を使うキーホルダー・スタンド）のうち、絵に囲まれた透明なすき間がある絵柄。
  指摘の 4 件では 2 件（1000169 / 1000174）が該当する
- 製品では、透けて見えるはずの所に白インキの面ができる。製造委託先・購入者から指摘は出ていない
- 製造データは「受注元 × 商品コード × サイズ × バリアント」で再利用される（REQ-0020）ため、同じ商品の再注文にも同じデータが渡る
- 回避策: なし（製造委託先が手作業で白版を削れば直るが、運用上は求められない）

## 受入基準

- [ ] 「再現手順」を実行しても再現しないこと（1000169 のかごの持ち手の輪の内側、1000174 の耳とピアノのあいだが白版で埋まらないこと）
- [ ] 中まで半透明の絵がある穴（1000169 のかごの編み目のすき間など。REQ-0067 が埋めたかった部分）は、今どおり埋まること
- [ ] 再発を検知する回帰テストが追加されていること
- [ ] 製造委託先が、直した白版のサンプルで OK を出すこと（REQ-0067 の補正は製造委託先の確認を通しているため）
- [ ] 本番で、指摘の 2 件（1000169 / 1000174）の製造データが作り直されていること

## スコープ外

- 販売サイト側の白版画像の作り方（内寄せの幅など）の変更
- 外周の切れ込みを埋める規則（REQ-0067 の 2 つ目）と、小さな孤立点を消す規則（3 つ目）
