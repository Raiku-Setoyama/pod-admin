## 現象

製造委託先から至急の連絡があった（2026-10-26、江口さん経由）。

> ・アクリルフィギュア - 100x100mm - アクリル【個数】1個_1000174_1000115_1017
>
> カットラインが正常に作成されておりません。（添付の画像参照）

添付の画像（Illustrator の画面）では、絵柄はピアノを弾く女の子で、左に椅子、右にピアノがあり、
椅子とピアノの脚が床に着いている。本体の CutLine は**絵柄の下端付近の細長い形だけ**で、絵柄全体を囲んでいない。
形は、左端から小さな山を経て右端まで底辺に沿って伸びる線と、底辺中央の差し込みタブでできている。
生成はエラーにならず、製造データは製造委託先に納入された。

同じ製造データの印刷画像が透過されていない件は BUG-0004。

## 再現手順

**合成した入力での再現（確認済み、2026-10-26）:**

1. カットライン画像に、本体（楕円）と、底辺中央の土台（長方形）を描く。さらに土台の左右に、
   土台とすき間を空けて、**土台と同じ高さで下端が終わる脚**（細い長方形）を描く
2. `product_type=acrylic_stand` / `size=100x100mm` で生成する（ワーカー用／開発用のイメージで `app.generator.generate`）
3. → 期待と異なり、生成は成功し、本体の CutLine の高さが 26.5mm しかない（脚の無い入力では 76.5mm）。
   形は添付の画像と同じく、底辺に沿った線とタブだけになる

脚が土台より下へはみ出す入力（ADR-0038 の土台の延長が働く）や、脚が土台につながっている入力では再現しない。

**指摘の製造データ（1000174）の元データでの再現:** 未確認。本番のログ・バケット・DB を参照できる権限が
調査の手元に無く、元データ（受注明細の `source_images`）を取得できていない。

| | |
|---|---|
| 発生環境 | 本番（VectorCraft 版。2026-10-12 の切り替え以降）。ローカルでも合成した入力で再現する |
| 発生頻度 | 絵柄に依存する。土台以外にも、土台と同じ高さで床に着き、土台と離れた部分がある絵柄で毎回 |

## 違反している受入基準

> REQ-0067 の受入基準「アクリルスタンドの差し込みタブが ADR-0038 に従うこと（土台の延長、タブがテンプレートと同一、合成できなければ `failed`）」

タブは付いたが、本体の輪郭が失われたカットラインが成功として作られた。
ADR-0038 は、正しく合成できない入力を `failed` にして、壊れたデータを納入しないことを求めている。

## 影響範囲

- 指摘の 1000174 は、正しいデータが届くまで製造に着手できない
- 椅子・机・楽器など、脚が床に着く絵柄のアクリルスタンドで起こりうる。
  2026-10-12 以降に生成されたアクリルスタンドのうち、ほかに同じ状態のものがあるかは未確認
- 製造データは「受注元 × 商品コード × サイズ × バリアント」で再利用される（REQ-0020）ため、
  同じ商品の再注文にも同じデータが渡る
- 生成が成功扱いになるため、製造委託先が気づかなければ壊れたまま製造される。システム側で検知する手段が無い

## 受入基準

- [ ] 「再現手順」を実行しても再現しないこと（本体の輪郭を保ったまま、土台にタブが付くこと）
- [ ] タブを正しく合成できない入力は、生成が失敗として扱われ、壊れた製造データが `ready` にならないこと
- [ ] 再発を検知する回帰テストが追加されていること
- [ ] 本番で、指摘の製造データ（1000174）が作り直され、カットラインが絵柄全体を囲んでいること

## スコープ外

- 印刷画像の背景が透過されていない件（BUG-0004）
- 作り直した製造データの製造委託先への再納入（連絡と受け渡しは運用で行う）
