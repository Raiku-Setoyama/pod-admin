## プロジェクト概要

オリジナルグッズ（POD: Print-On-Demand）の**受注〜製造〜出荷を一元管理**するフルスタック Web アプリケーション。
株式会社 TOSYO の管理者が、外部販売サイトから API で取り込んだ受注をもとに、製造委託先（メーカー）への発注・製造データの生成・出荷・請求までを扱う。製造委託先は専用ポータルで自社の発注明細・発注資料・請求書・チャットを利用する。

## 目的・ゴール

- 受注〜出荷の状態を 1 システムで追跡し、手作業の集計・転記をなくす。
- 外部販売サイトからの受注取り込みと、製造データ生成を自動化する。
- 製造委託先との受け渡し（発注資料・請求書・連絡）をポータルで完結させる。

成功の定義は未確認（既存プロジェクトのため、顧客との合意水準の再確認が必要）。

## スコープ

### 対象

受注管理 / 商品・メーカーマスタ / メーカー発注・製造データ生成 / 配送管理 / 請求書発行 / チャット / ダッシュボード / 外部販売サイト連携 / 各種通知。詳細は `docs/01-requirements/` の要件（REQ-XXXX）を正本とする。
