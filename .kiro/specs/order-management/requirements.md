# 受注管理機能 要件定義

## 概要

外部販売サイト（RKSYO等）からAPI経由で受注情報・製造データを受信し、システムに登録・管理する機能。

---

## 要件

### 1. 受注API エンドポイント

#### 1.1 受注登録API

**説明**: 外部販売サイトから受注情報と製造データを受け付けるAPIエンドポイント

**受入条件**:
- システムは、認証済みのリクエストを受信した場合、受注データを登録すること
- システムは、必須項目（注文番号、商品ID、商品名、価格、購入者名、郵便番号、住所、電話番号、注文日時）が不足している場合、400エラーを返却すること
- システムは、商品IDが商品マスタに存在しない場合、404エラーを返却すること
- システムは、同一注文番号が既に存在する場合、409エラーを返却すること
- システムは、受注登録成功時、受注IDを含むレスポンスを返却すること

#### 1.2 製造データ受信

**説明**: 受注と共に製造データ（デザインデータ、白おさえデータ、カットラインデータ等）を受信・保存する

**受入条件**:
- システムは、製造データをマルチパートフォームデータとして受信すること
- システムは、受信した製造データを加工・変換せずそのまま保存すること
- システムは、製造データのファイル名、パス、サイズを受注レコードに記録すること
- システムは、製造データが添付されていない場合でも受注登録を許可すること

### 2. API認証・セキュリティ

#### 2.1 API認証

**説明**: 外部販売サイトからのAPIリクエストを認証する

**受入条件**:
- システムは、有効なAPIキーまたはJWTトークンを持たないリクエストに対し、401エラーを返却すること
- システムは、認証情報をAuthorizationヘッダーで受け付けること

### 3. データバリデーション

#### 3.1 入力バリデーション

**説明**: 受注データの入力値を検証する

**受入条件**:
- システムは、注文番号が50文字を超える場合、バリデーションエラーを返却すること
- システムは、商品名が200文字を超える場合、バリデーションエラーを返却すること
- システムは、価格が0未満の場合、バリデーションエラーを返却すること
- システムは、数量が1未満の場合、バリデーションエラーを返却すること
- システムは、メールアドレス形式が不正な場合、バリデーションエラーを返却すること

### 4. 受注データ管理

#### 4.1 受注ステータス

**説明**: 受注のステータスを管理する

**受入条件**:
- システムは、新規受注を「pending（受注済み・発注前）」ステータスで登録すること
- システムは、以下のステータス遷移を許可すること：
  - pending → ordered（発注済み）
  - ordered → manufacturing（製造中）
  - manufacturing → delivered（納入済み）
  - delivered → shipping（配送中）
  - shipping → completed（配送完了）

### 5. APIレスポンス仕様

#### 5.1 成功レスポンス

**説明**: 受注登録成功時のレスポンス仕様

**受入条件**:
- システムは、201ステータスコードと共に受注情報を返却すること
- レスポンスには以下を含むこと：
  - id（受注ID）
  - order_number（注文番号）
  - status（ステータス）
  - created_at（作成日時）

#### 5.2 エラーレスポンス

**説明**: エラー発生時のレスポンス仕様

**受入条件**:
- システムは、エラーレスポンスにエラーコードとメッセージを含むこと
- システムは、バリデーションエラー時に422ステータスコードと詳細なエラー情報を返却すること

### 6. パフォーマンス要件

#### 6.1 処理能力

**説明**: システムの処理能力要件

**受入条件**:
- システムは、1,000件/日以上の受注処理に対応すること
- システムは、単一APIリクエストを3秒以内に処理すること

## 入力データ仕様

### 受注APIリクエスト

| フィールド | 型 | 必須 | 説明 |
|-----------|-----|------|------|
| order_number | string | ○ | 注文番号（最大50文字） |
| product_id | string | ○ | 商品ID（商品マスタに存在すること） |
| product_name | string | ○ | 商品名（最大200文字） |
| price | integer | ○ | 価格（0以上） |
| quantity | integer | - | 数量（1以上、デフォルト: 1） |
| customer_name | string | ○ | 購入者氏名（最大100文字） |
| customer_postal_code | string | ○ | 郵便番号（最大10文字） |
| customer_address | string | ○ | 住所 |
| customer_phone | string | ○ | 電話番号（最大20文字） |
| customer_email | string | - | メールアドレス |
| ordered_at | datetime | ○ | 注文日時（ISO 8601形式） |
| manufacturing_data | file | - | 製造データファイル |
