# Product Context

## Purpose

POD（プリント・オン・デマンド）グッズ受発注管理システム。オリジナルグッズの販売における受注から製造発注、配送までの業務を効率的に管理する。

## Core Capabilities

- **受注管理**: 外部販売サイト（RKSYO等）からAPI経由で受注情報・製造データを受信
- **発注管理**: メーカーへの製造発注と進捗管理
- **配送管理**: 納品後の配送依頼と追跡
- **マスタ管理**: 商品・メーカー情報の管理

## Target Users

| ユーザー | 役割 |
|---------|------|
| 管理者（社内オペレーター） | 受注確認、発注管理、配送管理、マスタ管理 |
| メーカー担当者 | 発注書・製造データのダウンロード、製造ステータス更新 |

## Product Scope

### 対象商品
- アクリルキーホルダー
- アクリルスタンド
- ステッカー
- マグカップ
- Tシャツ

### システム境界

```
[外部販売サイト] → [本システム] → [メーカー/配送業者]
```

**重要原則**: 製造データは外部販売サイトから受け取ったものをそのままメーカーへ渡す。本システムでの加工・整形は行わない。

## Business Value

- 受注から発注資料作成までの自動化
- メーカーとの効率的なコミュニケーション（専用ページ・チャット）
- 配送業務の効率化（ラベル印刷用CSV・梱包資料の自動生成）

## Non-Functional Requirements

| 項目 | 要件 |
|------|------|
| 処理量 | 1,000件/日、10,000件/月 以上 |
| 可用性 | 営業時間中（9:00-18:00）稼働 |
| セキュリティ | API認証必須、メーカーログイン認証 |
